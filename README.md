# FindBack – Campus Lost & Found System

## Overview
FindBack is a web-based campus Lost & Found System designed to help students and staff report, search, match, and recover lost items.

## Objective
To provide a simple and organized platform for managing lost and found items on campus.

## Stakeholders
- Students
- Faculty
- University Staff
- Administrators

## Key Features
- Lost Item Reporting
- Found Item Reporting
- Search & Matching
- Item Management
- User-Friendly Interface

## Project Prototype
The repository includes the UI prototype of the FindBack system.
